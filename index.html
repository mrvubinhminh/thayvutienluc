Tải file Excel — tự động nhận diện loại câu hỏi
Kéo-thả hoặc bấm để chọn một hoặc nhiều file .xlsx (đọc tất cả các sheet). Hỗ trợ file chuẩn dạng ngân hàng câu hỏi — một bảng gộp chung với cột "Loại" (Trắc nghiệm / Đúng-Sai / Trả lời ngắn) tự phân loại từng dòng — hoặc file chia riêng theo từng phần. Không cần chọn thủ công.

Hiển thị trước các phần câu hỏi. Cột dữ liệu: Tiêu đề, Tiêu đề nhỏ, Kiến thức, Link ảnh (Link ảnh không bắt buộc). Trong ô "Kiến thức", mỗi dòng (xuống dòng bằng Alt+Enter trong Excel) là một gạch đầu dòng — tối đa 10 dòng mỗi slide để chữ luôn to, trình bày chuẩn như PowerPoint. Nếu có Link ảnh, ảnh sẽ hiện ở nửa bên phải màn hình khi trình chiếu, có nút ẩn ảnh để mở rộng chữ ra toàn màn hình.
